# ✦ Gemini · ผู้เชี่ยวชาญการบริหารเงิน (LAB 2)

แชทบอทเว็บ (HTML / CSS / JavaScript) สำหรับตอบคำถามเรื่อง **การบริหารเงิน / การเงินส่วนบุคคล**
ดัดแปลงหลักการมาจาก **DL-04 – RAG System Development I** (retrieval + generation)

## สิ่งที่เปลี่ยนจาก LAB 1
| หัวข้อ | LAB 1 | LAB 2 (นี้) |
|--------|-------|-------------|
| ฐานความรู้ (Data) | ความรู้รอบตัวเรื่องรถยนต์ | **การบริหารเงิน** (งบประมาณ ออม ลงทุน หนี้ ภาษี เกษียณ) |
| ธีม/LLM | หน้าตาแบบ ChatGPT | **หน้าตาแบบ Gemini** (ไล่เฉดน้ำเงิน-ม่วง-ชมพู) |
| บทเรียนอ้างอิง | DL-03 Retrieval System | **DL-04** RAG System Development I |

> เรื่อง "เปลี่ยน LLM เป็น Gemini": ในโปรเจกต์ DL-04 คือการตั้งค่า
> `LLM_PROVIDER = "gemini"` (โมเดล `gemini-1.5-flash`) แทน `"openai"` (gpt-4o-mini)
> ส่วนหน้าเว็บนี้จำลองประสบการณ์/หน้าตาแบบ Gemini และตอบจากฐานความรู้แบบ retrieval

## วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome/Edge) — ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร
แล้วพิมพ์คำถามเรื่องการเงิน เช่น "เงินสำรองฉุกเฉินควรมีเท่าไหร่" → บอทจะตอบให้

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | หน้าเว็บ + ส่วนติดต่อผู้ใช้ (ธีม Gemini) |
| `style.css` | ตกแต่งหน้าตาแบบ Gemini (ไล่เฉดสี การ์ดคำถาม กล่องพิมพ์) |
| `data.js` | ฐานความรู้เรื่องการบริหารเงิน รูปแบบ Q&A |
| `retriever.js` | ระบบค้นหาคำตอบด้วยความคล้าย (character n-gram cosine) |
| `script.js` | ควบคุมหน้าจอแชท เชื่อม UI กับ retriever |

## หลักการทำงาน
เมื่อผู้ใช้ถาม ระบบจะแปลงคำถามเป็นเวกเตอร์ n-gram แล้วหาความคล้าย (cosine similarity)
กับคำถามในฐานความรู้ เลือกคำตอบที่ตรงที่สุดมาแสดง ถ้าคะแนนต่ำกว่าเกณฑ์ (นอกเรื่องการเงิน)
บอทจะแจ้งว่าไม่มีข้อมูล เป็นการจำลองแนวคิด retrieval ของ RAG ฝั่ง browser ล้วน

## เพิ่ม/แก้ไขความรู้
