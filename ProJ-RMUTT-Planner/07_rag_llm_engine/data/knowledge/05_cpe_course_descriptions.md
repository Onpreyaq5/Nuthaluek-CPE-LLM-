# กลุ่มวิชาชีพบังคับ ชั้นปีที่ 1

## 04100101-66 การเขียนโปรแกรมคอมพิวเตอร์
3(2-3-5) · ไม่มีวิชาบังคับก่อน

หลักการเขียนโปรแกรมเชิงโครงสร้าง ชนิดข้อมูล ตัวแปร ตัวดำเนินการ คำสั่งเงื่อนไข
คำสั่งวนซ้ำ ฟังก์ชัน อาร์เรย์ พอยน์เตอร์ การจัดการไฟล์ การแก้จุดบกพร่องของโปรแกรม
ฝึกปฏิบัติด้วยภาษา C และ Python

## 04100102-66 พื้นฐานวิศวกรรมคอมพิวเตอร์
3(3-0-6) · ไม่มีวิชาบังคับก่อน

ภาพรวมของวิชาชีพวิศวกรรมคอมพิวเตอร์ ระบบเลขฐาน การแทนข้อมูลในคอมพิวเตอร์
องค์ประกอบของระบบคอมพิวเตอร์ ฮาร์ดแวร์และซอฟต์แวร์ ระบบเครือข่ายเบื้องต้น
จริยธรรมทางวิชาชีพ

## 04100103-66 โครงสร้างข้อมูลและอัลกอริทึม
3(2-3-5) · บังคับก่อน 04100101-66

โครงสร้างข้อมูลแบบลิสต์ สแตก คิว ต้นไม้ กราฟ ตารางแฮช การเรียงลำดับและการค้นหา
การวิเคราะห์ความซับซ้อนเชิงเวลาและพื้นที่ (Big-O) การออกแบบอัลกอริทึมแบบแบ่งแยกและเอาชนะ
และการโปรแกรมพลวัต

## 04100104-66 ดิจิทัลลอจิกและการออกแบบ
3(2-3-5) · บังคับก่อน 04100102-66

พีชคณิตบูลีน วงจรเชิงผสม วงจรเชิงลำดับ ฟลิปฟลอป เคาน์เตอร์ รีจิสเตอร์
การลดรูปด้วยแผนผังคาร์นอห์ การออกแบบวงจรด้วยภาษาบรรยายฮาร์ดแวร์ (HDL)

## 04100105-66 คณิตศาสตร์ดิสครีต
3(3-0-6) · ไม่มีวิชาบังคับก่อน

ตรรกศาสตร์ เซต ความสัมพันธ์ ฟังก์ชัน การพิสูจน์เชิงคณิตศาสตร์ การอุปนัย
ทฤษฎีจำนวน การนับและความน่าจะเป็นเบื้องต้น ทฤษฎีกราฟและต้นไม้

## 04100501-66 การพัฒนาแอปพลิเคชันบนอุปกรณ์เคลื่อนที่

## 04100506-66 ระบบสารสนเทศเพื่อการจัดการ
บทบาทของระบบสารสนเทศในองค์กร ระบบวางแผนทรัพยากรองค์กร ระบบสนับสนุนการตัดสินใจ
