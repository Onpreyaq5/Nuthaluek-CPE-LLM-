# ข้อกำหนดเพิ่มเติมของหลักสูตร CPE

1. นักศึกษาต้องผ่านรายวิชา **04100305-66 เตรียมโครงงาน** ก่อนลงทะเบียน **โครงงาน 1**
   และผ่าน **โครงงาน 1** ก่อนลงทะเบียน **โครงงาน 2**
2. รายวิชาสหกิจศึกษา ลงได้เฉพาะภาคการศึกษาสุดท้าย และต้องผ่านวิชาชีพบังคับ
   ไม่น้อยกว่า 48 หน่วยกิต
3. รายวิชาที่มีรหัสลงท้ายต่างปีหลักสูตร (เช่น `-62`, `-63`, `-66`) ให้ยึดตามปีหลักสูตร
   ที่นักศึกษาสังกัด หากต้องการลงข้ามปีหลักสูตรต้องยื่นคำร้องเทียบรายวิชาที่ฝ่ายวิชาการคณะ
