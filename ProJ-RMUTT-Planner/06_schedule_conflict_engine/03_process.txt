ALGORITHM: TIME CLASH
  slots(section) = OR ของทุก meeting → 182-bit mask
  conflict(a,b)  = slots(a) & slots(b) != 0
  ถ้าชน → หาช่วงที่ทับจริง (เอา bit ที่ซ้อน map กลับเป็นเวลา) เพื่อบอกผู้ใช้

ALGORITHM: AUTO PLAN (ลำดับการทำ)
  1. ดึง eligible sections จาก 05 (ผ่าน prereq + ตรงหลักสูตร + ที่นั่งว่าง)
  2. จัดลำดับความสำคัญวิชา:
       P0 วิชาบังคับที่ค้าง/เคยได้ F
       P1 วิชาบังคับตามแผนเทอมนี้
       P2 วิชาที่ปลดล็อกวิชาอื่นเยอะ (critical path)
       P3 วิชาเลือก/เสรี
  3. สร้างโมเดล CP-SAT ตามข้อจำกัดใน 02_step
  4. solve (timeout MAX_SOLVER_SECONDS)
  5. ถ้าไม่มีคำตอบ → relax ทีละชั้น: ที่นั่ง → ความชอบ → หน่วยกิตสูงสุด
     แล้วบอกผู้ใช้ว่า "ต้องยอมอะไรบ้าง" (ห้ามคืน error เปล่า)
  6. จัดอันดับ candidates ด้วยคะแนน + ความหลากหลาย
