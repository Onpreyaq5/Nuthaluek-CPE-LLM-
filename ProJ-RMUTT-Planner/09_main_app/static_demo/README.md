# หน้าเดโมไฟล์เดียว (GitHub Pages)

เปิดใช้งานจริงได้ที่ **https://onpreyaq5.github.io/Nuthaluek-CPE-LLM-/**

## ทำไมต้องมีอีกตัว

ตัวเต็มใน `09_main_app` ต้องมีฟังก์ชัน Python ฝั่งเซิร์ฟเวอร์ (`api/*.py`) จึงต้อง deploy ที่ Vercel
หน้านี้ยกตรรกะไปไว้ในเบราว์เซอร์ทั้งหมด เลยวางบน GitHub Pages ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย
และไม่ต้องสมัครบริการอะไรเพิ่ม — เอาไว้ให้เพื่อนหรืออาจารย์กดเปิดดูได้ทันที

| | ตัวเต็ม (Vercel) | หน้านี้ (GitHub Pages) |
|---|---|---|
| จัดตารางเรียน + ตรวจชน C1–C6 / W1–W5 | ✓ | ✓ (ตรรกะเดียวกัน พอร์ตเป็น JS) |
| ค้นหารายวิชา | ✓ | ✓ |
| ถามเรื่องระเบียบ (RAG) | ✓ | ✗ ต้องใช้เซิร์ฟเวอร์ |
| ส่งออกไฟล์ปฏิทิน `.ics` | ✓ | เปลี่ยนเป็นคัดลอกเป็นข้อความ |
| ต้องมีเซิร์ฟเวอร์ | ✓ | ✗ |

## โครงไฟล์

```
static_demo/
├── template.html   เนื้อหน้าทั้งหมด (CSS + JS + โครงสร้าง) มี placeholder __TIMETABLE_DATA__
├── build.py        ยัดตารางสอนจาก data/seed/*.json ลง placeholder แล้วเขียนเป็น docs/index.html
└── README.md       ไฟล์นี้
```

`docs/index.html` ที่ได้คือไฟล์เดียวจบ ไม่มี dependency ภายนอกนอกจากฟอนต์จาก Google Fonts

## สร้างใหม่หลังแก้ข้อมูลหรือแก้หน้า

```bash
python ProJ-RMUTT-Planner/09_main_app/static_demo/build.py
```

แล้ว commit `docs/index.html` ที่เปลี่ยนไปด้วย GitHub Pages จะ deploy ให้เองภายในไม่กี่นาที

## ข้อควรระวัง

ตรรกะใน `template.html` เป็นการ**พอร์ต**มาจาก `api/_core/conflicts.py` และ `api/_core/planner.py`
ไม่ได้แชร์โค้ดกัน **ถ้าแก้ตรรกะฝั่ง Python แล้วต้องตามไปแก้ใน `template.html` ให้ตรงกันด้วย**
ไม่งั้นสองหน้าจะตอบไม่เหมือนกัน

จุดที่ต่างกันโดยตั้งใจ:

- ฝั่ง JS คำนวณ bitmask เองจาก `meetings` ด้วย `BigInt` ไม่ใช้ `slots_mask` ที่มากับ JSON
  เพราะ mask กว้าง 182 บิต แต่ `JSON.parse` ของ JS เก็บได้แม่นแค่ 53 บิต บิตล่างจะหายเงียบ ๆ
- หน้านี้มีสวิตช์ "ถือว่าผ่านวิชาของชั้นปีก่อนหน้ามาแล้ว" ที่อนุมานจากชั้นปี
  ใช้เพื่อปลดล็อกวิชาบังคับก่อนเท่านั้น ไม่ได้เอาไปขึ้น C5 ว่าเคยผ่านแล้ว เพราะเป็นการเดา
  ตัวเต็มใช้ `passed_courses` จริงจากข้อมูลนักศึกษาแทน
