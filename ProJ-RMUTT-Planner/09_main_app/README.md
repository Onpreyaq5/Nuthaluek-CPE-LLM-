# 09 — Main App (เว็บที่ใช้งานจริง)

> เจ้าของพื้นที่: **เฟิส** — สมาชิกคนอื่นแก้โมดูล 01–08 ของตัวเอง ไม่ต้องแก้โฟลเดอร์นี้

เว็บแอปที่รวมงานของทุกคนเข้าด้วยกัน ใช้งานได้จริงบนเบราว์เซอร์ ไม่ต้องติดตั้งอะไร
**Next.js (หน้าเว็บ) + Python serverless (ตรรกะ)** ขึ้น Vercel ได้ฟรี

---

## ใช้งานอะไรได้

| หน้า | ทำอะไร |
|---|---|
| `/` | หน้าแรก อธิบายว่าระบบตรวจอะไรให้บ้าง |
| `/planner` | **จัดตารางเรียน** — เลือกวิชา เห็นตารางทันที ตรวจชนแบบเรียลไทม์ มีปุ่มให้ระบบจัดให้ |
| `/courses` | ค้นหารายวิชา หมู่เรียน เวลา อาจารย์ ที่นั่งคงเหลือ |
| `/chat` | ถามเรื่องระเบียบ/หลักสูตร ตอบพร้อมแหล่งอ้างอิง |

**สิ่งที่ผู้ใช้ทำได้จริง**
- เลือกวิชา → เห็นตารางสัปดาห์ทันที วิชาที่ชนขึ้นกรอบแดง
- กดปุ่มเดียวให้ระบบจัดตารางให้ ตามชั้นปีและเงื่อนไข (ไม่เอาคาบเช้า / ขอวันว่าง / เพดานหน่วยกิต)
- กดปุ่ม "เปลี่ยนเป็น ..." ในกล่องแจ้งปัญหา เพื่อสลับหมู่เรียนแก้การชนทันที
- ส่งออกเป็นไฟล์ `.ics` เปิดใน Google Calendar หรือปฏิทินมือถือ
- แผนถูกจำไว้ในเบราว์เซอร์ ปิดแล้วเปิดใหม่ยังอยู่

## รันในเครื่อง

```bash
cd 09_main_app
npm install

# หน้าต่างที่ 1 — ฟังก์ชัน Python
python scripts/dev_server.py

# หน้าต่างที่ 2 — หน้าเว็บ
PY_DEV_URL=http://127.0.0.1:8009 npm run dev
```

เปิด http://localhost:3000

> บน Vercel ไม่ต้องรัน `dev_server.py` เพราะ `api/*.py` กลายเป็น serverless function เอง
> สคริปต์นี้มีไว้จำลองพฤติกรรมนั้นตอนพัฒนาในเครื่องเท่านั้น

## ขึ้น Vercel

**1. เชื่อม repo**

ที่ [vercel.com/new](https://vercel.com/new) เลือก repo `Nuthaluek-CPE-LLM-` แล้วตั้งค่า:

| ช่อง | ค่า |
|---|---|
| Root Directory | `ProJ-RMUTT-Planner/09_main_app` |
| Framework Preset | Next.js (ตรวจเจอเอง) |
| Build Command | ปล่อยว่าง |
| Install Command | ปล่อยว่าง |

**2. ใส่ Environment Variables** (ไม่ใส่ก็ใช้งานได้)

| ชื่อ | ค่า | จำเป็นไหม |
|---|---|---|
| `GEMINI_API_KEY` | คีย์จาก [Google AI Studio](https://aistudio.google.com/apikey) | ไม่จำเป็น |
| `GEMINI_MODEL` | `gemini-2.0-flash` | ไม่จำเป็น |

ไม่ใส่คีย์ → แชทใช้โหมดอ้างอิงเอกสารตรง ๆ ยังตอบได้และ**ไม่มีวันมั่ว** เพราะไม่ได้แต่งข้อความเอง
ใส่คีย์ → คำตอบเป็นภาษาธรรมชาติขึ้น โดยยังอ้างอิงเอกสารเหมือนเดิม

**3. กด Deploy** — ได้ URL สาธารณะใช้งานได้ทันที

หรือใช้ CLI:
```bash
cd ProJ-RMUTT-Planner/09_main_app
npx vercel
```

## ทำไมไม่ยก 8 container มาไว้บน Vercel

Vercel เป็น serverless ไม่ได้รัน container และจำกัดขนาดฟังก์ชันที่ **250 MB**

| โมดูล | ติดตรงไหน | ทำยังไง |
|---|---|---|
| 06 | `ortools` ~180 MB | ยกเฉพาะ **ตรรกะตรวจการชน** (bitmask) ที่ไม่ต้องใช้ ortools มาไว้ใน `api/_core/conflicts.py` ส่วนการจัดตารางใช้ greedy แทน CP-SAT |
| 05 | `pythainlp` ~250 MB | ตัดคำไทยด้วย character n-gram (3,4) แทน |
| 07 | — | ยกมาได้ทั้งดุ้น เพราะใช้ stdlib อยู่แล้ว |
| 02, 08 | ต้องมี Postgres + Redis | ไม่ยกมา — เว็บนี้เก็บแผนไว้ใน localStorage ของเบราว์เซอร์แทน |

**ผลคือ `requirements.txt` ว่างเปล่า** ฟังก์ชันใช้ stdlib ล้วน cold start เร็วและ deploy ฟรีได้

ระบบเต็ม (มี CP-SAT, ฐานข้อมูล, Celery) ยังอยู่ครบใน `docker-compose.yml` ที่ root
เว็บนี้คือเวอร์ชันที่ตัดให้เล็กพอจะขึ้นฟรีและใช้งานได้จริง

## API

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| GET | `/api/courses?term=1/2569&q=&year=` | รายวิชา + หมู่เรียน + ที่นั่งคงเหลือ |
| POST | `/api/validate` | ตรวจตารางชน คืน C1–C6 / W1–W5 |
| POST | `/api/autoplan` | จัดตารางให้ตามชั้นปีและเงื่อนไข |
| GET | `/api/chat` | สถานะ + ขอบเขตข้อมูลที่ระบบมี |
| POST | `/api/chat` | ถาม-ตอบจากเอกสาร พร้อมแหล่งอ้างอิง |

รหัสปัญหาและข้อความภาษาไทยตรงกับโมดูล 06 ทุกตัว ถ้าภายหลังอยากเรียก 06 ตัวจริง
ผ่าน HTTP ก็เปลี่ยนแค่ `api/validate.py` โดยไม่ต้องแก้หน้าเว็บ

## ข้อจำกัดที่ต้องรู้

1. **ข้อมูลเป็นชุดจำลอง** — ตารางสอน ระเบียบ ปฏิทิน สร้างขึ้นเพื่อสาธิต ไม่ใช่ของจริง
   ทุกหน้ามีข้อความเตือนกำกับไว้แล้ว
2. **ไม่มีระบบล็อกอิน** — แผนเก็บใน localStorage ของเบราว์เซอร์
   เปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์แล้วแผนจะหาย จึงมีปุ่มส่งออก `.ics` ไว้ให้
3. **จัดตารางใช้ greedy ไม่ใช่ CP-SAT** — ได้แผนที่ใช้ได้จริงและไม่ชน
   แต่ไม่รับประกันว่าดีที่สุดเชิงคณิตศาสตร์เหมือนโมดูล 06
4. **ยังไม่มีตารางสอนภาคฤดูร้อน** — มีเฉพาะ 1/2569 และ 2/2569
