# 09 — Main App Integration (First only)

> เจ้าของพื้นที่: **เฟิส (หัวหน้าทีม GitHub)**

โฟลเดอร์นี้เป็นพื้นที่ประกอบและตรวจสอบแอปเวอร์ชันหลักที่ต้องใช้งานได้จริง สมาชิกคนอื่น **ห้ามแก้ไข ย้าย หรือลบไฟล์ในโฟลเดอร์นี้** เว้นแต่เฟิสจะมอบหมายโดยตรง

## วิธีทำงานของทีม

1. สมาชิกแต่ละคนแก้เฉพาะโฟลเดอร์โมดูลที่ได้รับมอบหมาย ตั้งแต่ 01_web_app ถึง 08_recommendation_feedback
2. ก่อนเริ่มงานให้รัน `git pull origin main` ทุกครั้ง
3. Commit และ push เข้า `main` ได้โดยตรง โดย add เฉพาะโฟลเดอร์ของตนเอง
4. เฟิสตรวจงานจากแต่ละโมดูล แล้วนำมารวมและทดสอบใน `09_main_app`
5. เวอร์ชันที่ถือว่าใช้งานได้จริงให้ยึดจากพื้นที่นี้และไฟล์ส่วนกลางที่เฟิสดูแล

## พื้นที่ที่สงวนให้เฟิส

- `09_main_app/`
- `docker-compose.yml`
- `Makefile`
- `.env.example`
- `infra/`
- การแก้ contract ที่เชื่อมหลายโมดูลพร้อมกัน

> GitHub ไม่สามารถจำกัดสิทธิ์เป็นรายโฟลเดอร์เมื่อทุกคนมีสิทธิ์ Write และ push เข้า main โดยตรง กติกานี้จึงเป็นข้อตกลงของทีมที่ทุกคนต้องปฏิบัติตาม
