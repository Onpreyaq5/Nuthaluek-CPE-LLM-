```

   │
   ├─(1) เช็คเบื้องต้นในเบราว์เซอร์ → เปลี่ยนสีทันที (<16ms)  [UX เท่านั้น]
   │
   └─(2) POST /api/v1/plans/validate  {sections:[...]}          (02_api_backend)
            │
            ├─ ดึง student context ──────────────▶ (05) GET /context/{id}
            ├─ ดึงรายละเอียด section ────────────▶ (04) cache redis
            │
            └─ POST /conflicts/check ────────────▶ (06) SCHEDULE ENGINE
                     │
                     ├ C1 เวลาทับ?      bitmask AND
                     ├ C2 สอบชน?
                     ├ C3 prereq ครบ?
                     ├ C4 หน่วยกิตเกิน?
                     ├ C5 ลงซ้ำ?
                     ├ C6 ที่นั่งเต็ม?
                     └ W1-W5 คำเตือนคุณภาพชีวิต
                     │
                     ▼ conflicts[] (structured)
            ┌────────┴─────────┐
            ▼                  ▼
   ตอบกลับ frontend      POST /explain/plan ──▶ (07) LLM แปลงเป็นภาษาคน
   (ทาสีแดง + badge)              │
                                  ▼
              "ENG101 ม.01 (จ. 09:00-12:00) ชนกับ MTH102 ม.02 (จ. 09:00-10:30)
               ครับ — ลองเปลี่ยนเป็น MTH102 ม.05 (พฤ. 13:00-14:30) ดูไหม"
            │
            └─(3) log ไป (08) แบบ async
```

## FLOW B — "จัดตารางเทอมหน้าให้หน่อย" (Auto Plan)

```
นักศึกษา กด "ให้ AI จัดให้" + ตั้งค่าความชอบ (ไม่เรียนเช้า / อยากว่างศุกร์)
   │
   ▼  POST /plans/auto {term:"1/2569", preferences:{...}}        (02)
   │
   ├──▶ (05) สร้าง student context
   │      ├ วิชาที่ผ่านแล้ว / ค้าง / ได้ F
   │      ├ หน่วยกิตเหลือแต่ละหมวด
   │      └ prereq graph → วิชาที่ "ปลดล็อกแล้ว"
   │
   ├──▶ (04) ดึงวิชาที่เปิดสอนเทอมนั้น + ทุก section
   │
   ├──▶ (06) AUTO PLANNER (CP-SAT)
   │      hard:  1 วิชา 1 sec, ห้ามเวลาทับ, หน่วยกิต 9-22, prereq ครบ, มีที่นั่ง
   │      soft:  +ความก้าวหน้าหลักสูตร  +ตรงความชอบ  −ช่องว่าง  −จำนวนวันมาเรียน
   │      ▼
   │      ได้ 3-5 แผนทางเลือก (เรียงตามคะแนน)
   │      ถ้าไม่มีคำตอบ → ผ่อนเงื่อนไขทีละชั้น + บอกว่าต้องยอมอะไร
   │
   ├──▶ (07) เขียนคำอธิบายแต่ละแผน + ข้อดี/ข้อเสีย + อ้างอิงระเบียบถ้าเกี่ยว
   │
   └──▶ (08) ประกอบผลลัพธ์: ตาราง + .ics + ความเสี่ยง + แจ้งเตือนวันลงทะเบียน
              ▼
        แสดง 3 แผนให้เลือก → ผู้ใช้เลือก/แก้เอง → save
              ▼
        feedback "ทำไมไม่เอาแผนนี้" → (08) → (05) อัปเดต preference
```

## FLOW C — "ถอนรายวิชาได้ถึงเมื่อไหร่?" (RAG Q&A)

```
ข้อความจากผู้ใช้ → POST /chat (SSE)                              (02)
   ▼
(03) AI ROUTER
   ├ classify intent = REGULATION_QA (conf 0.92)
   ├ slot: {topic:"ถอนรายวิชา", term:"1/2569"}
   └ tools = [get_student_context, search_knowledge]
   ▼
(07) RAG
   ├ rewrite query → "การถอนรายวิชา ระเบียบ กำหนดเวลา W"
   ├ hybrid: BM25(top20) + vector(top20) → RRF → rerank → top6
   ├ filter: หลักสูตรปี 2566 ของผู้ใช้ (กฎแต่ละปีไม่เหมือนกัน)
   ├ score สูงสุด < 0.35 ? → ตอบ "ไม่พบข้อมูล ติดต่อ สวท." (จบ)
   └ LLM generate (stream) + citations
   ▼
คำตอบ + [อ้างอิง: ข้อบังคับฯ ข้อ 18 หน้า 12] + ปุ่ม 👍/👎
   ▼
(08) log {intent, latency, tokens, cost} + feedback
```

## FLOW F — "วางแผนเรียนให้จบ" จากข้อมูลจริงในระบบทะเบียน  ★ ใช้ได้ทั้งคนปัจจุบันและน้องปี 2

```
นักศึกษาล็อกอิน oreg3.rmutt.ac.th เอง (ระบบเราไม่แตะรหัสผ่าน)
   │
   ├─ หน้า "ตรวจสอบจบ"  (graduate_check.asp)  → Ctrl+S → graduate_check_<id>.html
   └─ หน้า "ค้นหารายวิชา" คณะวิศวะ เทอมนี้     → Ctrl+S → search_<เทอม>.html
   │
   ▼  อัปโหลดผ่านหน้าเว็บ (01) → POST /students/me/import  (02)
   │
   ├──▶ (05) graduate_check.py
   │       ├ header: หน่วยกิตขั้นต่ำ 143 / ปีสูงสุด 8 / GPAX ต่ำสุด 2.00
   │       ├ หมวด 0, 1, 1.1, 1.1.1, 2.1 ...  → หน่วยกิตต่ำสุด / ผ่านแล้ว / เหลือ / ผ่าน-ไม่ผ่าน
   │       └ รายวิชา → เทอมที่ลง + เกรด (ครั้งที่ 1-5) → ผ่าน / ต้องลงใหม่ / ยังไม่ลง
   │
   ├──▶ (04) oreg_rmutt.parse_search_results  → วิชาที่เปิดเทอมนี้ + กลุ่ม + ที่นั่งเหลือ
   │     (04) oreg_rmutt.parse_course_detail  → วัน/เวลา/สอบ ของแต่ละกลุ่ม
   │
   ├──▶ (05) degree_plan.py  รวมสองอย่างเป็น "รายการวิชาที่ควรลง"
   │       P0 เคยลงแล้วไม่ผ่าน (F / W / ไม่สอบ)          ← ต้องลงใหม่ก่อน
   │       P1 หมวดที่ยัง "ไม่ผ่าน" / หน่วยกิตต่ำกว่าเกณฑ์
   │       P2 วิชาที่ปลดล็อกวิชาอื่น (prereq graph)
   │       P3 ที่เหลือ
   │       + ติดป้ายว่าเทอมนี้ "เปิดกี่กลุ่ม" หรือ "ไม่เปิด"
   │
   ├──▶ (06) จัดตารางจาก candidates ที่เปิดจริง → ไม่ชน + หน่วยกิตตามเกณฑ์
   │
   └──▶ (07)+(08) อธิบาย: "เหลืออีก 63 หน่วยกิต, หมวด 2.1 ขาด 23,
                  ฟิสิกส์ต้องลงใหม่แต่เทอมนี้ไม่เปิด → ลงเทอม 2/2569 แทน, คาดว่าจบ 2/2570"

สำหรับน้องปี 2 ที่ยังไม่มีประวัติ: หน้าตรวจสอบจบจะโชว์โครงสร้างทั้งหลักสูตร (ทุกวิชา = ยังไม่ลง)
→ candidates = ทั้งหลักสูตร → ระบบเรียงตาม suggested_year/term + prereq → ได้ "แผน 4 ปี" ตั้งแต่วันแรก
```
