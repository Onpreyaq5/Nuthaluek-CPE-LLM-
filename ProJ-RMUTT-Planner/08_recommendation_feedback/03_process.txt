CONTINUOUS IMPROVEMENT LOOP
  ใช้งาน → log → วัดผล → หาจุดอ่อน → แก้ (prompt/เอกสาร/กฎ/น้ำหนัก scoring)
  → ปล่อย → วัดซ้ำ
  ประชุมทีมดู dashboard สัปดาห์ละครั้ง

METRIC ที่ทีมต้องตกลงกัน (ใส่ในรายงาน)
  - Conflict Detection Accuracy : ต้อง 100% (มันคือคณิตศาสตร์ ไม่ใช่ AI)
  - Plan Acceptance Rate        : % ที่ผู้ใช้กดใช้แผนที่ระบบเสนอ
  - Answer Accuracy (golden set): เป้า >= 85%
  - P95 latency                 : validate < 500ms, auto-plan < 10s, chat first token < 2s
  - Cost / active user / เดือน

PRIVACY (PDPA)
  - student_id เก็บเป็น hash ใน log
  - transcript/เกรด = ข้อมูลอ่อนไหว → เข้ารหัสที่ DB, เข้าถึงได้เฉพาะเจ้าของ
  - มีหน้าให้ผู้ใช้ "ลบข้อมูลของฉัน"
  - ก่อนส่ง context ให้ LLM cloud → ตัดชื่อ-นามสกุล-รหัสจริงออก ใช้ placeholder
  - ต้องมีหน้า consent ตอนใช้ครั้งแรก

DISCLAIMER (ต้องขึ้นทุกหน้าที่ให้คำแนะนำ)
