TradeRAG
สวัสดีครับ ผมคือระบบตอบคำถามเรื่องการเทรดที่ทำงานด้วยสถาปัตยกรรม RAG

ฐานความรู้ครอบคลุม ความรู้เบื้องต้น เช่น คำสั่งซื้อขาย การบริหารความเสี่ยง จิตวิทยาการเทรด และ ความรู้เทคนิคขั้นสูง เช่น Ichimoku, Elliott Wave, Wyckoff, Order Block, Volume Profile

ทุกคำตอบมาจากเอกสารในฐานความรู้เท่านั้น และจะแนบรหัสอ้างอิงให้ตรวจสอบได้เสมอ ถ้าไม่มีข้อมูลรองรับ ระบบจะบอกว่าไม่รู้ แทนการเดา
เนื้อหาเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน การเทรดมีความเสี่ยงต่อการสูญเสียเงินต้น

เอกสารที่ระบบใช้ตอบ

ยังไม่มีคำถาม — เอกสารอ้างอิงพร้อมคะแนนความเกี่ยวข้องจะแสดงที่นี่

ตัวกรองการค้นหา

ตัวกรองมีผลกับการค้นหาทันที ดูผลกระทบได้ที่แท็บตรวจสอบ Pipeline

ตรวจสอบการทำงานทีละขั้น

หน้านี้คือเครื่องมือหลักในการ ตรวจสอบปัญหา เพราะแสดงว่าระบบคิดอะไรในแต่ละชั้น ตั้งแต่แปลงคำถามจนถึงการตัดสินใจตอบหรือปฏิเสธ

กดปุ่มวิเคราะห์เพื่อดูการทำงานของ Pipeline ทีละขั้น

ปัญหาและการแก้ไขปัญหาของ RAG System

วิเคราะห์ปัญหาที่เกิดขึ้นจริงในแต่ละขั้นตอนของระบบนี้ พร้อม สาเหตุ · วิธีตรวจสอบ · แนวทางแก้ไข และตำแหน่งใน Source Code ที่แก้จริง — ทุกข้อกด ทดลองรัน เพื่อเทียบผลก่อนแก้กับหลังแก้ได้

ประเมินผลระบบด้วยตัวเลข

ชุดทดสอบ (Golden Set) สร้างจาก คำถามสำรอง ของทุกเอกสาร ซึ่งเขียนคนละสำนวนกับคำถามหลัก จึงวัดความสามารถในการค้นหาได้จริง ไม่ใช่การจับคู่ข้อความตรงตัว

กดปุ่มด้านบนเพื่อเริ่มการประเมินผล การคำนวณทั้งหมดทำงานในเบราว์เซอร์
