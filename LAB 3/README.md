## ระบบนี้คืออะไร

**TradeRAG** คือระบบตอบคำถามเรื่องการเทรดที่สร้างด้วยสถาปัตยกรรม RAG เต็มรูปแบบ
ฐานความรู้ครอบคลุมทั้ง **ความรู้เบื้องต้น** และ **ความรู้เทคนิคขั้นสูง**

| ชั้นความรู้ | หมวดหมู่ | ตัวอย่างหัวข้อ |
|------------|---------|---------------|
| **เบื้องต้น** | พื้นฐานการเทรด, บริหารความเสี่ยง, จิตวิทยา, เทคนิคเบื้องต้น, ปัจจัยพื้นฐาน, กฎหมาย | คำสั่งซื้อขาย 5 แบบ, กฎเสี่ยง 1-2%, คำนวณขนาดสถานะ, แนวรับแนวต้าน, FOMO |
| **ขั้นสูง** | อินดิเคเตอร์, รูปแบบราคา, Smart Money, กลยุทธ์และระบบ | Ichimoku, Elliott Wave, Wyckoff, Order Block, Fair Value Gap, Volume Profile, Backtesting |

> เนื้อหาเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน
> ระบบมี Safety Guard ที่ **ปฏิเสธ** คำถามประเภท "ควรซื้อตัวไหนดี" หรือ "ราคาพรุ่งนี้จะขึ้นไหม"

## สถาปัตยกรรม RAG

```
[ทำความสะอาด + ตัดซ้ำ] → [ตัด Chunk 420/80] → [ดัชนี TF-IDF + BM25]
                                                        ↓
[คำถาม] → [Normalize + ขยายคำพ้อง + Multi-Query] → [Hybrid Retrieval 5 รายการ + RRF]
                                                        ↓
                                              [กรอง Metadata]
                                                        ↓
                                          [Re-ranking ผู้สมัคร 12 ชิ้น]
                                                        ↓
                         [Safety Guard] → [Grounding Check ≥ 0.30] → [เรียบเรียง + อ้างอิง]
```

### จุดที่ออกแบบต่างจาก RAG ทั่วไป

| จุด | เหตุผล |
|-----|--------|
| **แยก `grounding` ออกจาก `score`** | คะแนนจัดอันดับบอกแค่ว่า *ชิ้นไหนดีที่สุดในกลุ่มนี้* ไม่ได้บอกว่า *ดีพอหรือยัง* การใช้ค่าเดียวทำสองหน้าที่ทำให้ด่านกัน Hallucination ถูกหลอกได้ |
| **coverage ถ่วงน้ำหนักด้วย IDF** | ภาษาไทยตัดด้วย n-gram ได้ชิ้นส่วนทั่วไปจำนวนมาก ถ้านับเท่ากันหมด คำถามนอกขอบเขตก็ได้คะแนนสูง |
| **แยกรายการค้นหาตามแหล่งที่มา + ถ่วงน้ำหนัก** | คำถามเดิม 1.00, คำพ้องที่คัดมาเอง 0.90, รูปแบบที่ระบบเดาเอง 0.45 |
| **แบ่งคำถามสำรองเป็นชุดดัชนี/ชุดทดสอบ** | ถ้าใช้ข้อความชุดเดียวกันทั้งเข้าดัชนีและทดสอบ คะแนนจะสวยเกินจริงจนสรุปผิด |

## ผลการประเมินจริง

**ชุดทดสอบ:** 90 คำถามที่กันไว้ ไม่เคยเข้าดัชนีและไม่เคยใช้ตอน Re-ranking

| ชุดค่า | Hit@1 | Hit@3 | Hit@5 | MRR | nDCG@5 |
|--------|-------|-------|-------|-----|--------|
| BM25 อย่างเดียว | 56.7% | 68.9% | 75.6% | 0.646 | 0.668 |
| Vector อย่างเดียว | 56.7% | 68.9% | 75.6% | 0.644 | 0.667 |
| Hybrid (RRF) | 57.8% | 70.0% | 76.7% | 0.653 | 0.678 |
| Hybrid + ขยายคำพ้อง | 61.1% | 76.7% | 85.6% | 0.710 | 0.738 |
| **Hybrid + คำพ้อง + Rerank** | **75.6%** | **90.0%** | **92.2%** | **0.829** | **0.851** |

**ด่านความปลอดภัย:** ดักคำถามนอกขอบเขตได้ 9 จาก 10 โดยปฏิเสธคำถามที่ถูกต้องผิดเพียง 3.3%

## ปัญหา 11 ข้อที่วิเคราะห์

| # | ขั้นตอน | ปัญหา |
|---|---------|-------|

| 04 | Query | คำถามสั้นหรือกำกวมเกินกว่าจะค้นแม่น |
| 05 | Retrieval | ใช้วิธีค้นเพียงวิธีเดียวแล้วแพ้คำถามบางประเภท |
| **05.1** | Retrieval | **การขยายคำพ้องทำให้ผลแย่ลง** — พบจากการวัดผล |
| 06 | Ranking | เอกสารที่ถูกต้องถูกจัดอันดับไว้ต่ำเกินไป |
| 07 | Filtering | ตัวกรอง Metadata ที่ตั้งผิดทำให้คำตอบหาย |

| **09** | Evaluation | **ชุดทดสอบรั่ว ทำให้คะแนนสวยเกินจริง** — เกิดขึ้นจริงและแก้แล้ว |

### ตัวอย่างที่ชัดที่สุด — ปัญหา 09
รันประเมินผลครั้งแรก BM25 เปล่า ๆ ได้ Hit@1 ถึง **98.2%** ส่วนระบบเต็มรูปแบบได้ 95.5%
การที่ระบบพื้นฐานที่สุดชนะระบบที่ใส่เทคนิคครบ คือสัญญาณว่า **การวัดผลมีอะไรผิด**
เมื่อตรวจสอบพบว่าคำถามทดสอบถูกใส่ไว้ในดัชนีตั้งแต่แรก การวัดจึงกลายเป็นการค้นข้อความที่ตรงกันทุกตัวอักษร

ถ้าไม่พบปัญหานี้ ข้อสรุปของรายงานจะกลายเป็น *"BM25 เปล่า ๆ ก็พอแล้ว เทคนิคอื่นไม่จำเป็น"* ซึ่งผิดทั้งหมด

## เทคโนโลยีที่ใช้

- **HTML / CSS / JavaScript ล้วน** ไม่ใช้ framework ไม่ใช้ build step
- **TF-IDF Vector Space Model** ทำหน้าที่แทน Dense Embedding
- **BM25** (k1 = 1.5, b = 0.75) สำหรับการค้นด้วยคำตรงตัว
- **Reciprocal Rank Fusion** สำหรับรวมผลจากหลายวิธี
- **Character n-gram (2–3)** สำหรับตัดคำภาษาไทยที่เขียนติดกัน
- **เชื่อมต่อ LLM จริงได้** (Gemini / OpenAI) เป็นทางเลือก ปิดไว้เป็นค่าเริ่มต้น

### ข้อจำกัดที่ระบุไว้อย่างตรงไปตรงมา
ระบบใช้ TF-IDF แทน Embedding Model เชิงความหมายจริง เพราะต้องรันบนเบราว์เซอร์ล้วนโดยไม่ต้องใช้ API Key
ข้อจำกัดที่ตามมาคือ ระบบไม่เข้าใจความหมายของคำที่ไม่เคยเห็นคู่กัน จึงต้องชดเชยด้วยพจนานุกรมคำพ้อง 47 กลุ่ม
และมีคำถามนอกขอบเขตบางรูปแบบที่ยังหลุดผ่านด่านได้ รายละเอียดอยู่ใน [PROBLEMS.md ปัญหา 08](PROBLEMS.md#ปัญหา-08)
