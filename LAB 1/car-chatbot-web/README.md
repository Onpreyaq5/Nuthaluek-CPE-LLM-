# 🚗 ผู้เชี่ยวชาญความรู้รอบตัวเรื่องรถ

แชทบอทเว็บง่ายๆ (HTML / CSS / JavaScript) สำหรับตอบคำถามความรู้รอบตัวเกี่ยวกับรถยนต์
ดัดแปลงหลักการมาจาก **DL-03 – LLM Retrieval System** (retrieval-based QA)
โดยเปลี่ยนฐานความรู้จากเรื่องเดิม → **ความรู้รอบตัวเรื่องรถยนต์**

## วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร)
แล้วพิมพ์คำถามเกี่ยวกับรถ เช่น "ควรเปลี่ยนน้ำมันเครื่องบ่อยแค่ไหน" → บอทจะตอบให้

> แนะนำให้เปิดในเบราว์เซอร์จริง (Chrome/Edge) เพื่อให้ CSS และ JavaScript ทำงานครบถ้วน

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | หน้าเว็บ + ส่วนติดต่อผู้ใช้ (คล้าย ChatGPT) |
| `style.css` | ตกแต่งหน้าตา (กล่องพิมพ์ทรงแคปซูล ธีมขาวสะอาด) |
| `data.js` | ฐานความรู้เรื่องรถยนต์ รูปแบบ Q&A (แทน `data/sex_q_a.txt` เดิม) |
| `retriever.js` | ระบบค้นหาคำตอบด้วยความคล้าย (แทน `src/retriever.py` เดิม) |
| `script.js` | ควบคุมหน้าจอแชท เชื่อม UI กับ retriever |

## หลักการทำงาน (เทียบกับ DL-03 ต้นฉบับ)
| DL-03 (Python) | เวอร์ชันเว็บนี้ (JavaScript) |
|----------------|------------------------------|
| แปลงข้อความเป็น embedding | แปลงเป็นเวกเตอร์ character n-gram (bi/tri-gram) |
| ค้นด้วย cosine similarity บน FAISS | ค้นด้วย cosine similarity ในหน่วยความจำ |
| คืน top-k คำตอบ | คืนคำตอบที่ตรงที่สุด (top-1) |

เมื่อผู้ใช้ถาม ระบบจะหาคำถามในฐานความรู้ที่ "คล้าย" ที่สุดแล้วส่งคำตอบกลับมา
ถ้าคะแนนความคล้ายต่ำเกินเกณฑ์ (นอกเรื่องรถ) บอทจะบอกว่าไม่มีข้อมูล

## เพิ่ม/แก้ไขความรู้
แก้ไฟล์ `data.js` โดยเพิ่มบล็อกในรูปแบบ:
```js
{
  category: "หมวดหมู่",
  question: "คำถาม",
  answer: "คำตอบ"
}
```
